1. Présentation de SafeCity

SafeCity Lubumbashi est une solution numérique de sécurité citoyenne qui permet à un citoyen de signaler un danger en un geste depuis son téléphone, et au centre de surveillance de recevoir, localiser et traiter l'alerte en temps réel, en coordonnant les agents d'intervention sur le terrain.

La plateforme se compose de trois applications connectées à un serveur central :

ApplicationPublicRôle
📱 Application citoyenne (web)Citoyens Déclencher une alerte, partager sa position GPS, joindre photo / message vocal
🖥️ Poste opérateur (bureau)Centre de contrôle / Mairie Superviser, affecter les équipes et agents, communiquer, analyser
👮 Portail des agents (web)Agents de terrain Recevoir les alertes, se localiser, accepter et terminer les interventions

Le cœur technique : Backend Flask (API REST + temps réel Socket.IO), PostgreSQL, IA de classification des incidents (scikit-learn), cartographie OpenStreetMap/Leaflet, sécurité bcrypt + JWT.

3. Installation & déploiement

a) En production (serveur / VPS) — une seule commande

ssh root@VOTRE_IP
apt update && apt install -y git
git clone <dépôt> safecity && cd safecity
sudo bash deploy/install.sh

Le script installe Docker, génère la configuration (domaine sslip.io proposé automatiquement, secrets générés), ouvre les ports, émet le certificat HTTPS (Let's Encrypt) et démarre toute la pile. À la fin :

  • Application citoyenne : https://VOTRE-DOMAINE/
  • Portail agents : https://VOTRE-DOMAINE/portal/
  • API (santé) : https://VOTRE-DOMAINE/api/health
💡 HTTPS sans acheter de domaine : le service sslip.io transforme votre IP en nom valide (ex. 203.0.113.10 → 203-0-113-10.sslip.io).

b) Démonstration locale (Docker)

docker compose up --build
# App citoyenne :8080 · Portail agents :8090 · API :5000

c) Développement (sans Docker)

pip install -r requirements.txt
python -m backend.server                     # backend :5000
cd web && python -m http.server 8080         # app citoyenne
cd portal && python -m http.server 8090      # portail agents
pip install PySide6 && python desktop/main.py # poste opérateur (bureau)

5. Application citoyenne (web)

Interface simple et rassurante, utilisable sur téléphone (installable en application — PWA — et fonctionnelle hors-ligne).

Écran d'accueil : le bouton d'alerte

Comment signaler une alerte

  1. Ouvrir SafeCity et appuyer sur le gros bouton 🚨 ALERTE.
  2. La position GPS est récupérée automatiquement.
  3. Choisir le type de danger (vol, braquage, incendie, accident, violence, autre).
  4. Optionnel : saisir son nom / téléphone, une description, ajouter une photo ou un message vocal.
  5. Appuyer sur Envoyer l'alerte : une confirmation s'affiche avec la carte.
📴 Mode hors-ligne : sans réseau, l'alerte est enregistrée sur le téléphone et renvoyée automatiquement dès le retour de la connexion.

À l'arrivée d'une alerte

Un son d'alarme retentit, une fenêtre d'incident s'ouvre automatiquement (citoyen, téléphone, GPS, urgence, média) et un badge « non lu » apparaît sur le menu concerné. L'opérateur peut : Accepter Envoyer une patrouille Affecter un agent Appeler Ouvrir la carte Clôturer

7. Portail des agents d'intervention

Interface web pour les agents sur le terrain : alertes en direct, carte, position GPS partagée, et gestion des interventions.

Portail agents : alertes en direct et carte

Déroulé d'une intervention

  1. L'agent se connecte et autorise la géolocalisation (sa position remonte au centre).
  2. Une alarme sonne à l'arrivée d'une alerte ; l'opérateur peut la lui assigner.
  3. L'agent clique ✅ Accepter : l'itinéraire le plus rapide se trace vers l'incident.
  4. Sur place, il clique 🏁 Terminer l'intervention pour clôturer.
  5. Il peut consulter 📜 Mes interventions (historique) et échanger via la messagerie.

9. Sécurité & sauvegardes

  • Mots de passe hachés avec bcrypt ; sessions par jetons JWT.
  • Rôles & permissions : administrateur, superviseur, opérateur, agent, citoyen.
  • Anti force brute (limitation des connexions), validation stricte des entrées et des fichiers, en-têtes de sécurité, CORS restreint.
  • HTTPS/TLS partout via Nginx + Let's Encrypt (renouvellement automatique).
  • Sauvegardes PostgreSQL automatiques (pg_dump périodique + rotation).
  • Journal des connexions et des actions (logs applicatifs).
